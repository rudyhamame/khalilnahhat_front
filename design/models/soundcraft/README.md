# Soundcraft soundboard

Photo-guided illustrative mixing console: inclined blue-grey panel, black cabinet, 12 mono input strips, stereo strips, effects controls, channel faders and two yellow master faders. Exact variant, dimensions and electrical ratings are unverified.

Built with local Blender 4.5.9 LTS using `build_model.py`; join static GLB material groups with `@gltf-transform/cli join`. Frontend equipment key: `soundcraft`. Camera starts above the controls, with rotation/zoom and fixed position. Delivery files live in Cloudinary.
