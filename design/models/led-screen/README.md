# LED screen

Photo-guided illustrative modular LED cabinet pair showing both display and rear enclosure. Dimensions, pixel pitch and electrical ratings are unverified. The supplied reference texture is embedded with face UVs; no external texture request is needed by the GLB.

[GLB](https://res.cloudinary.com/nqiooluk/raw/upload/v1793070020/khalil/site-assets/ae2da9d1dfb2/echo/models/led-screen.glb) · [Preview](https://res.cloudinary.com/nqiooluk/image/upload/v1793070018/khalil/site-assets/5ead19074c5b/echo/models/led-screen-preview.png) · [Blender source](https://res.cloudinary.com/nqiooluk/raw/upload/v1793070019/khalil/site-assets/b66f62a67a4c/echo/models/led-screen.blend) · [Reference photo](https://res.cloudinary.com/nqiooluk/image/upload/v1793069926/khalil/site-assets/2dc6428a64da/echo/models/led-screen-reference.webp)

Built with local Blender 4.5.9 LTS using `build_model.py`, then `@gltf-transform/cli join`. Equipment key: `led-screen`. Source image is packed into the Blender file. No frontend deployment.
