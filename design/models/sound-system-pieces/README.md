| Dashboard equipment | Model file |
| --- | --- |
| Pole-mounted speakers | pole-mounted-speaker.glb |

The pole-mounted speaker includes the mounting pole and has no tripod.
Photo-guided illustrative models: exact manufacturer models, dimensions and technical ratings are unverified.
