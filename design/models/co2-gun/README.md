# CO₂ gun with tank

Photo-guided illustrative MOKA SFX effects gun with a generic silver tank and connecting hose. Tank is not visible in the reference and is not a verified equipment match. Hardware only, no plume. Capacity, pressure, dimensions and operating ratings are unverified.
