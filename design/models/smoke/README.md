# Smoke machine

Photo-guided illustrative upright-output machine: black vented cabinet, top outlet with red LED ring, pale fluid reservoir, cap and hose, side carry handles and cables. Hardware only; no simulated plume. Exact identity, dimensions and operating ratings are unverified.
